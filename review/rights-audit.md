# Data protection and copyright audit: what the book publishes

Branch `book` at `e947a55`, audited on 2 Oct 2026. Nothing has been changed yet; this file only lists findings and recommendations.

**Scope.** Two audiences see different things:

- **Site**: the rendered book (`_book/`, later `gh-pages`): the chapters, `images/` used by them, `include/`, `data/`, and everything the pages load from other servers.
- **Repo**: everything in the public GitHub repository, including `question-bank/`, `PLAN_book.md` and the old files on `main`.

**Legend.** Recommendation: **keep** (as is or with attribution) · **replace** · **remove**. Priority: **P0** must be fixed before `quarto publish` · **P1** before merging or publishing · **P2** soon after.

---

## 0. Blocking finding (P0)

**The built site's home page is the old single-page site.** The chapters link to `../index.html`. Because the old root `index.html` still exists, Quarto copies it into `_book/` as a resource and overwrites the book's own `index.html`. `md5` of `_book/index.html` equals the old `index.html`.

If `quarto publish` ran today, the home page would:

- show real survey output from the original `reponses_socio.csv` (`str()` and `summary()` of the real data);
- load `https://polyfill.io/v3/polyfill.min.js`. That domain was taken over in 2024 and used to inject malicious scripts into visitors' browsers;
- lose the anchor-redirect script and the book's welcome page.

**Recommendation: remove** `index.html`, `index_files/` and `index.pdf` from the `book` branch before publishing. Publish to `gh-pages` and switch the Pages source *before* merging into `main`, so the live site never breaks (see §7).

## 2. External resources loaded automatically (privacy)

These are fetched by every visitor's browser, which sends their IP address to the third party without consent.

| Resource | Where | Issue | Recommendation |
|---|---|---|---|
| `https://polyfill.io/v3/polyfill.min.js` | Only via the stale `index.html` (§0) | Compromised domain (2024 supply-chain attack) | **Remove** with the old `index.html` (P0). |
| Google Fonts (`fonts.googleapis.com`, Source Sans Pro) | Every page; imported by the Bootswatch **cosmo** theme | IP transfer to Google; German courts have found this unlawful under GDPR (LG München, 2022) | **Replace**: self-host the font, or turn the web font off. Bootswatch supports `$web-font-path: false` in a custom SCSS layer; then use a system font stack. |
| YouTube iframe `youtube.com/embed/u1cc1r_Y7M0` | Session 12 (régression) | Loads YouTube and sets tracking cookies on page load | **Replace** with `youtube-nocookie.com/embed/…`, or with a plain link or thumbnail. |
| Wikimedia and Posit images (hotlinked) | Sessions 1, 2, 4 | IP transfer to Wikimedia and Posit; images may change or disappear | **Replace** with local copies (allowed by CC BY / CC BY-SA / PD; see §1 for Posit and the poster). |
| MathJax (`cdn.jsdelivr.net`), polyfill (`cdnjs.cloudflare.com`) | Pages with maths (Quarto default) | IP transfer to CDNs; low risk | **Keep**, or self-host later (`html-math-method` with a local copy). |

Plain links (YouTube videos, CRAN, DataCamp, Wikipedia, 24heures.ch, etc.) load nothing until clicked: **keep**.

## 6. Licence of the book

Currently `LICENSE` is the **MIT** licence (© 2024 Julian Maitra), and `_quarto.yml` has `license: "MIT"`. MIT is a software licence: it fits the code but not the prose, exercises and figures.

**Proposal**

- **Text, exercises, explanations and own figures: CC BY 4.0.** Set `license: "CC BY"` in `_quarto.yml`, which makes Quarto add the licence badge and link.
- **Code (R snippets in the chapters, `_common.R`, `data-raw/`): MIT.** Keep `LICENSE` as `LICENSE-CODE` or state the split in `LICENSE.md`.
- **Data**: own data (`reponses_socio.csv` synthetic, points, `ice_age_df.csv`): CC BY 4.0 (or CC0). `igposts.csv` is **excluded**; see §3.
- **Third-party items keep their own licences** and must be listed: Wikimedia images (CC BY-SA 4.0, CC BY 2.0, PD), palmerpenguins logo (CC0), webexercises files (CC BY-SA 4.0).

**To check first.** The PPUR edition: a CC BY licence on the web version lets anyone reuse the text, including commercially. Confirm with PPUR that this is compatible with the publishing contract (some publishers require exclusive rights, or accept only CC BY-NC-ND for the open version). Also check whether colleagues or assistants co-authored any Moodle questions; if so, they need to agree to the licence.

- **forks and clones**, and caches such as the Wayback Machine for the live site.

**Recommendation.** Decide with the UniFR data protection office whether to rewrite the history (`git filter-repo` on the paths above, then force-push all branches) and ask GitHub Support to purge cached views and unreachable commits.
