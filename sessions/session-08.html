8  Manipuler des données : pratique guidée

ImportantObjectifs d’apprentissage
  • Traduire une question en une suite de verbes de dplyr.
  • Combiner group_by() et summarize() pour comparer des groupes.
  • Créer une variable dérivée (un rapport, p. ex. des likes par follower) et interpréter le résultat.
  • Repérer une variable confondante dans une comparaison de moyennes.

Au chapitre 7, vous avez découvert les verbes de dplyr. Ce chapitre est entièrement pratique : quinze exercices, regroupés en trois blocs, vous demandent de répondre à des questions concrètes sur des jeux de données que vous connaissez déjà. Essayez chaque exercice dans votre propre script avant d’afficher la solution.

8.1 Préparation

Les exercices suivants se composent d’une question et d’une solution modèle sous forme de code R. Notez qu’en programmation R, il y a souvent plusieurs solutions pour arriver à la réponse correcte.

AstuceAstuce

Pour un meilleur effet d’apprentissage : essayez d’abord de résoudre la question avec votre propre script R sans consulter immédiatement la solution modèle. Comparez ensuite votre propre code avec celui de la solution modèle.

  • Ouvrez votre projet RStudio et créez un nouveau script R.

  • Nommez-le script_chapitre_8 et enregistrez-le dans le dossier du projet.

  • Chargez le package tidyverse avec library(tidyverse).

Exercice 7 — Comparer des groupes

  • Calculez le prix moyen en USD des diamants des différentes catégories de pureté (clarity) dans diamonds.
  • Triez le résultat par ordre décroissant des prix moyens
  • Quelle catégorie de pureté est la plus chère en moyenne dans diamonds ?
diamonds %>%
    group_by(clarity) %>%
    summarize(prix_moyen = mean(price)) %>%
    arrange(desc(prix_moyen))
# A tibble: 8 × 2
  clarity prix_moyen
  <ord>        <dbl>
1 SI2          5063.
2 SI1          3996.
3 VS2          3925.
4 I1           3924.
5 VS1          3839.
6 VVS2         3284.
7 IF           2865.
8 VVS1         2523.
# Avec un prix par diamant de 5063 USD en moyenne, la
# catégorie de pureté SI2 est la plus chère dans diamonds.

Cela ne veut pas dire qu’une pureté plus faible rend un diamant plus cher. Les diamants SI2 sont en moyenne plus lourds (1,08 carat, contre 0,51 pour la pureté maximale IF), et le poids influence fortement le prix. Comparez avec diamonds %>% group_by(clarity) %>% summarize(mean(carat)). C’est un exemple de variable confondante.

Exercice 10 — Construire un indicateur : prix par carat

  • Utilisez les verbes de dplyr pour calculer la moyenne des prix en USD par carat dans diamonds.
  • Montrez les résultats, triés par ordre décroissant de dollars par carat, pour les différentes catégories de taille (cut).
  • Montrez aussi n, le nombre de diamants par catégorie de taille.
diamonds %>%
    select(carat, cut, price) %>%
    mutate(USD_per_carat = price/carat) %>%
    group_by(cut) %>%
    summarize(n = n(), mean_USD_per_carat = mean(USD_per_carat)) %>%
    arrange(desc(mean_USD_per_carat))

ImportantEn bref
  • Partez de la question, puis choisissez les verbes : quelles lignes (filter()), quelles colonnes (select()), quel calcul (mutate(), summarize()), quel ordre (arrange()) ?
  • group_by() suivi de summarize() donne un résultat par groupe ; n() compte les observations de chaque groupe.
  • Une différence entre groupes peut venir d’une autre variable (ici le poids des diamants) : c’est une variable confondante.
  • Il existe souvent plusieurs solutions correctes ; l’essentiel est que le résultat réponde à la question.

Le chapitre « Révision 3 » vous permet de vérifier vos acquis sur l’importation et la manipulation de données.

Question 8.1

Exécutez le code suivant, puis jugez chaque proposition. Les unités américaines sont converties : 1 pouce (inch) = 2,54 cm et 1 livre (pound) = 0,4536 kg.

library(tidyverse)
data(women)
print(women)
?women
women %>% summarize(n = n(),
                    taille_moyenne_cm = mean(height * 2.54),
                    poids_moyen_kg = mean(weight * 0.4536))

  1. women est un jeu de données contenant les tailles et les poids de 15 femmes américaines âgées de 20 à 39 ans.

igposts %>% count(Type)

Question 8.9

Exécutez le code suivant pour savoir si l’affirmation est vraie ou fausse : la Toyota Corolla est le modèle de voiture le plus économe en carburant par rapport à son poids dans le jeu de données mtcars.

library(tidyverse)
data(mtcars)
mtcars %>%
  select(mpg, wt) %>%
  mutate(mpg_par_livre = mpg / wt) %>%
  arrange(desc(mpg_par_livre))

La première ligne du résultat est la Lotus Europa, suivie de la Honda Civic. La Toyota Corolla a le mpg le plus élevé, mais pas le meilleur rapport mpg / poids.
