5.1 Les nuages de points

Commençons par le nuage de points, que nous avons déjà vu au chapitre 4 pour représenter la relation entre le poids en carats et le prix des diamants.

NoteDéfinition : nuage de points

Un nuage de points (angl. scatter plot) est utilisé dans ggplot2 pour représenter les valeurs de deux variables numériques différentes par des points, avec une variable sur l’axe des X et l’autre sur l’axe des Y.

Ce type de graphique est idéal pour l’analyse exploratoire de données, permettant d’observer les relations entre les variables, de détecter des tendances, des regroupements, des valeurs extrêmes (angl. outliers) ou de vérifier des hypothèses de corrélation.

Avec ggplot2, un nuage de points se crée avec la géométrie geom_point().

Créons un nuage de points avec le jeu de données iris, en comparant les longueurs et les largeurs des sépales des iris (les variables Sepal.Length et Sepal.Width).

Notez que, dans le code suivant, nous ne créons pas directement un graphique ggplot mais nous stockons le graphique comme un objet dans l’environnement, nommé np1, que nous pouvons ensuite afficher avec la fonction print(). Nous verrons dans un instant pourquoi cette pratique est utile.

# nuage de points basique pour comparer la longueur et la
# largeur des sépales des iris
np1 <- ggplot(data = iris, mapping = aes(x = Sepal.Length, y = Sepal.Width)) +
    geom_point() + labs(title = "Longueur et largeur des sépales des iris")

print(np1)

Nous pouvons ajouter des couches à l’objet np1 sans l’écraser, p. ex. une ligne de régression linéaire avec geom_smooth(method = lm) :

np1 + geom_smooth(method = lm, formula = y ~ x)

Que nous indique la ligne de régression ? En principe, elle indique une corrélation légèrement négative (deux variables sont corrélées si elles varient ensemble : positivement si elles augmentent ensemble, négativement si l’une diminue quand l’autre augmente) entre les variables Sepal.Length et Sepal.Width (la zone grise autour de la ligne bleue est l’intervalle de confiance à 95 % de la droite de régression ; la régression linéaire est présentée au chapitre 12).

Cela signifie que les iris dont les sépales sont plus longs ont tendance à avoir des sépales un peu moins larges. Gardez cette constatation à l’esprit pour les étapes de codage suivantes.

# Écrasons np1 en changeant un peu le code. Repérez ce qui
# a changé dans le code.
np1 <- ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width, color = Species,
    shape = Species)) + geom_point() + labs(title = "Longueur et largeur des sépales des iris")

print(np1)

Vous pouvez voir dans le graphique que nous pouvons maintenant différencier les trois espèces d’iris, par la couleur et par la forme des points (la forme aide aussi les personnes qui distinguent mal les couleurs). La dispersion des points semble moins aléatoire, ce qui permet de voir des groupes de points appartenant à l’une ou l’autre espèce (angl. cluster).

Maintenant, ajoutons à nouveau une couche geom_smooth() à l’objet np1 :

np1 + geom_smooth(method = lm, formula = y ~ x)

Les trois lignes de régression (une pour chaque type d’iris) montrent maintenant un tout autre résultat : en effet, la corrélation entre Sepal.Length et Sepal.Width est clairement positive.

Ce renversement s’appelle le paradoxe de Simpson : une tendance globale peut s’inverser lorsqu’on tient compte d’une variable de groupe (ici l’espèce).

Cette constatation est un exemple d’analyse exploratoire des données, rendue possible par les possibilités de visualisation de ggplot2.

5.2 Les diagrammes en barres

NoteDéfinition : diagramme en barres

Les diagrammes en barres dans R avec ggplot2 sont utilisés pour représenter visuellement des données catégorielles, permettant de comparer des quantités entre différentes catégories.

On les utilise donc souvent pour montrer l’effectif ou la proportion d’observations dans chaque catégorie, ce qui les rend utiles pour analyser des tendances ou des différences au sein de données catégorielles.

Avec ggplot2, un diagramme en barres se crée avec la géométrie geom_bar().

Par exemple, nous pouvons utiliser le code simple suivant pour comparer les effectifs des différentes qualités de taille (cut) dans le jeu de données diamonds. Cette fois-ci, nous sauvegardons et nommons le graphique db1.

db1 <- ggplot(data = diamonds, mapping = aes(x = cut)) + geom_bar()

print(db1)

Améliorons le graphique avec des arguments et des éléments supplémentaires (Notez que nous allons simplement écraser l’objet db1 créé précédemment avec une nouvelle version de db1 !) :

library(ggthemes)

db1 <- ggplot(data = diamonds, mapping = aes(x = cut, fill = cut)) +
    geom_bar() + labs(title = "Effectifs des qualités de taille des diamants",
    subtitle = "n = 53 940 diamants", x = "Qualité de la taille",
    y = "Effectif") + theme_minimal()

print(db1)

Que nous dit le graphique ? Il est intéressant de constater que dans le jeu de données diamonds, le niveau de qualité le plus élevé de la taille, à savoir ideal, est également le plus fréquent.

AvertissementAttention

Dans la fonction ggplot(), il y a une différence si vous voulez ajouter de la couleur aux points (qui ont mathématiquement zéro dimension) ou aux surfaces (qui ont deux dimensions), comme dans les diagrammes en barres.

Si vous voulez ajouter de la couleur à une surface, vous devez utiliser l’argument fill = "xyz". L’argument color = "xyz" que nous avons utilisé pour ajouter de la couleur aux nuages de points ne fera que colorer le contour de la surface.

5.3 Les histogrammes

NoteDéfinition : histogramme

Un histogramme est un type de graphique utilisé pour représenter la distribution d’une variable numérique à travers des barres.

« Un histogramme sépare les valeurs possibles des données en classes ou groupes. Pour chaque groupe, on construit un rectangle dont la base correspond aux valeurs de ce groupe et la hauteur correspond au nombre d’observations dans le groupe.

L’histogramme a une apparence semblable au graphique à barres verticales, mais il n’y a pas d’écart entre les barres.

En règle générale, l’histogramme possède des barres d’une largeur égale. » (Statistique Canada, 2021)

L’histogramme est particulièrement utile pour :

  • Analyser la distribution : Comprendre si les données sont normalement distribuées, asymétriques (angl. skewness), ou si elles ont des queues plus ou moins épaisses que la loi normale (kurtosis).
  • Détecter les valeurs extrêmes : Identifier les données qui s’écartent nettement du reste des données.
  • Comparer des distributions : Observer comment différentes sous-populations se comparent les unes aux autres en termes de distribution de données.

Avec ggplot2, on crée un histogramme avec la géométrie geom_histogram(). Par défaut, geom_histogram() découpe les données en 30 intervalles (angl. bins) et affiche un message invitant à choisir une meilleure valeur. On peut fixer la largeur des intervalles avec l’argument binwidth (p. ex. geom_histogram(binwidth = 30)) ou leur nombre avec bins.

Avant de créer un histogramme avec le code R, introduisons d’abord une nouvelle fonction : rnorm(). Elle peut être utilisée pour créer des valeurs aléatoires qui suivent une loi normale (angl. normal distribution).

Les arguments que nous pouvons entrer dans la fonction sont :

  • le nombre n de valeurs aléatoires que nous voulons créer

  • la moyenne mean de la distribution des valeurs aléatoires

  • l’écart-type sd de la distribution des valeurs aléatoires

Notez que par défaut, la fonction utilise mean = 0 et sd = 1, ce qui correspond à une loi normale centrée réduite (angl. standard normal distribution).

Consultez aussi ?rnorm pour plus d’informations.

AstuceAstuce

La fonction set.seed() dans R est utilisée pour définir la graine (angl. seed) du générateur de nombres aléatoires. La graine est un nombre entier qui sert de point de départ pour le générateur de nombres aléatoires.

En définissant une graine spécifique, par exemple avec set.seed(123), vous garantissez que la séquence de nombres aléatoires générée par la suite avec des fonctions telles que rnorm(), sera la même à chaque fois que vous exécuterez le code, ce qui est utile pour la reproductibilité des résultats.

Dans le code R suivant, nous utilisons rnorm() pour simuler les distributions des tailles des hommes et des femmes en Suisse.

D’après l’Enquête suisse sur la santé 2017 (Müller et al., 2022), les femmes mesurent en moyenne 164,6 cm (écart-type 6,5 cm) et les hommes 177,0 cm (écart-type 7,1 cm). Dans la suite, nous utilisons des valeurs proches : une moyenne de 164,7 cm pour les femmes et de 177,4 cm pour les hommes, avec des écarts-types un peu plus petits de 5,6 cm et de 6,1 cm.

taille_f <- rnorm(500, mean = 164.7, sd = 5.6)

5.4 Les boîtes à moustaches

NoteDéfinition : boîte à moustaches

Les boîtes à moustaches (angl. boxplots) représentent la distribution d’une variable numérique à l’aide de cinq valeurs clés :

  1. l’extrémité de la moustache inférieure
  2. le premier quartile (Q1 ; début de la boîte)
  3. la médiane (Q2 ; ligne qui « coupe la boîte en deux »)
  4. le troisième quartile (Q3 ; fin de la boîte) et
  5. l’extrémité de la moustache supérieure.

Les moustaches s’étendent jusqu’aux valeurs les plus extrêmes situées à moins de 1,5 × l’écart interquartile de la boîte ; les valeurs au-delà sont dessinées comme des points (valeurs extrêmes potentielles). Les moustaches correspondent donc au minimum et au maximum seulement s’il n’y a pas de valeurs extrêmes.

Ces diagrammes permettent d’identifier rapidement la médiane, l’écart interquartile (angl. interquartile range, IQR) et les valeurs extrêmes potentielles. Ils sont particulièrement utiles pour comparer les distributions entre plusieurs groupes ou variables.

Le jeu de données mtcars, qui contient des données sur les caractéristiques de différents modèles de voitures, peut être utilisé pour illustrer l’utilisation des boîtes à moustaches.

Par exemple, pour visualiser la distribution de l’efficacité énergétique (mpg, miles par gallon) des voitures en fonction du nombre de cylindres (cyl), on peut utiliser le code suivant :

# Avant de créer le boxplot, vérifions d'abord la structure
# de mtcars :
str(mtcars)

 $ drat: num  3.9 3.9 3.85 3.08 3.15 2.76 3.21 3.69 3.92 3.92 ...

Nous pouvons constater que la colonne cyl (cylindre) est stockée au format numérique.

C’est un problème, car nous voulons comparer l’efficacité énergétique (mpg) des voitures à 4, 6 ou 8 cylindres. Nous devons traiter chacune d’entre elles comme un sous-groupe distinct. Comment faire ?

# Transformons donc cyl en facteur (voir le chapitre 2)
mtcars$cyl <- as.factor(mtcars$cyl)

# Et maintenant nous pouvons construire notre boxplot
box1 <- ggplot(data = mtcars, aes(x = cyl, y = mpg, fill = cyl)) +
    geom_boxplot(alpha = 0.2) + labs(title = "Consommation (mpg) selon le nombre de cylindres",
    x = "Nombre de cylindres", y = "Miles par gallon (mpg)")
print(box1)

Ce code crée un graphique, box1, avec une boîte à moustaches par groupe de cylindres du jeu de données mtcars, permettant de comparer facilement l’efficacité énergétique (mpg) entre les voitures avec des nombres de cylindres différents.

AstuceAstuce

L’argument alpha = 0.2 de geom_boxplot() rend les boîtes transparentes. En général, alpha peut être compris entre 0 (totalement transparent) et 1 (non transparent). C’est un argument supplémentaire qui permet de personnaliser votre graphique ggplot2.

Le graphique montre que dans mtcars, les voitures avec des moteurs ayant plus de cylindres ont aussi tendance à être moins efficaces en termes de consommation de carburant. Il existe toutefois quelques intersections entre les groupes. C’est-à-dire qu’il y a des voitures à 8 cylindres qui sont relativement efficaces en termes de consommation de carburant, surpassant quelques voitures à 6 cylindres, par exemple.

ImportantEn bref
  • Nuage de points : deux variables numériques ; diagramme en barres : une variable catégorielle ; histogramme : la distribution d’une variable numérique ; boîte à moustaches : une variable numérique comparée entre groupes.
  • color colore les points et les contours, fill remplit les surfaces.
  • La largeur des intervalles (binwidth) change beaucoup l’aspect d’un histogramme : essayez plusieurs valeurs.
  • Une tendance d’ensemble peut s’inverser quand on distingue des groupes (paradoxe de Simpson) : regardez aussi vos données par sous-groupe.
  • rnorm() simule des valeurs suivant une loi normale ; set.seed() rend la simulation reproductible.
