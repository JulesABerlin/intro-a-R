Bienvenue

Ce site propose une introduction pas à pas au langage R pour l’analyse de données en sciences sociales, et en particulier en sciences de la communication. Chaque chapitre combine des explications, du code à exécuter dans RStudio et des exercices interactifs avec corrections.

📄 Télécharger le livre en PDF (avec corrigés en annexe)

NoteOrigine de ce site

Ce matériel a été développé pour le cours Exercices Méthodes II du Bachelor en sciences de la communication de l’Université de Fribourg, que j’ai enseigné de 2023 à 2025. Il s’adresse à toute personne qui souhaite apprendre R à son rythme.

Comment utiliser ce site

  • Suivez les chapitres dans l’ordre : chacun s’appuie sur les précédents.
  • Exécutez vous-même le code dans RStudio et modifiez-le : on apprend R en l’utilisant.
  • Testez-vous avec les exercices à la fin de chaque chapitre. Les chapitres « Révision » reprennent les tests du cours.
  • Sur ce site, les exercices sont interactifs ; dans la version PDF, les réponses se trouvent dans l’annexe « Corrigés ».

Les jeux de données utilisés dans le cours se trouvent dans le dossier data/ et peuvent être lus directement depuis le site, par exemple :

igposts <- read.csv("https://julesaberlin.github.io/intro-a-R/data/igposts.csv",
                    encoding = "UTF-8")
